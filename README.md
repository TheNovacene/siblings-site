# Siblings

A small browser game for two people who have to share a keyboard, from the world of *The Drowned Stack* and *Who Lives Between?* (Novacene Press, 2026).

Live at https://siblings.novacenepress.com/ — served by GitHub Pages from this repository, DNS at Cloudflare.

One file does all the work: `index.html` (canvas, no build step, no dependencies beyond two Google Fonts).

Windows before doors.
